# ADR 0001: Headless Simulation Engine, Maps Decoupling, and Keyboard Grid Accessibility

## Контекст (Context)
Гра **Alik vs Sahko** — це тактична 2D-стратегія Tower Defense у сетингу космічної колонії.
Для забезпечення найвищої якості коду, можливості тестування та доступності виникли такі потреби:
1. **Ізоляція симуляції від рендерингу**: Ігровий цикл не повинен бути прив'язаний до DOM або конкретного розміру Canvas.
2. **Масштабованість мап та локацій**: Маршрути ворогів, розміри сіток та перешкоди повинні завантажуватися з типізованих конфігурацій без модифікації ігрового рушія.
3. **Доступність (a11y) для гравців з обмеженнями зору та руху**: Canvas 2D є недоступним для екранних дикторів (screen readers) за замовчуванням. Необхідна віртуальна клавіатурна сітка з ARIA-оголошеннями.

## Рішення (Decision)
1. **Headless Engine**: Клас `TDGameEngine` реалізує чистий детермінований крок часу `update(dt)`. Уся логіка балістики, наведення лазерів, уповільнення та зняття броні покрита юніт-тестами.
2. **Maps Registry (`src/lib/game/maps.ts`)**: Мапи описуються структурами `GameMap` із чіткими розмірами, координатами вейпоінтів та маскою блокованих клітин (`isCellBuildable`).
3. **Bilingual Support (`src/lib/i18n/game.ts`)**: Двомовність UA/EN із паритетом ключів.
4. **Accessible Grid Navigation (`src/lib/game/a11y.ts`)**:
   - Віртуальний курсор сітки переміщується клавішами `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight` або `WASD`.
   - Будь-яка зміна фокуса або розміщення вежі транслюється в ARIA live region (`aria-live="polite"`).

## Наслідки (Consequences)
- 100% тестів рушія та мап проходять у середовищі Node без потреби браузерного Canvas.
- Проєкт повністю відповідає вимогам масштабованості та доступності за каноном v10.
